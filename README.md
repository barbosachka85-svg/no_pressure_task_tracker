# 🌸 Добрый трекер

Трекер задач, который не ругает, а хвалит.

Я написала его, когда поняла, что Asana и Habitica доводят до невроза моего внутреннего достигатора. Дедлайны, красные просрочки, отнятое здоровье за невыполненные дела — всё это работает как топливо для тревоги. Здесь всё наоборот: нет дат, штрафов и напоминаний, а есть сердечки за любой шаг вперёд.

## Как это устроено

- **Короткие задачи** — сделала и получила 💛 золотое сердечко.
- **Длинные задачи** можно отмечать 💚 зелёным сердечком, даже если ты просто немного над ними поработала. Задача остаётся в списке, а прогресс копится. Когда закончишь совсем — 💛 золотое сердечко.
- **Задача дня** — трекер случайно выбирает одну задачу, если не знаешь, с чего начать.
- **Статистика** за 7 и 30 дней показывает только то, что получилось. Сколько осталось недоделанным, она не считает, и это специально.
- **Таблица по дням** для длинных задач: видно, как сердечки складываются в прогресс.

## Что внутри

Мозг трекера написан на Python, данные хранятся в `tracker_data.json`. Есть два лица: консольное и приложение для Android. Оба используют одну и ту же логику и один формат файла.

| Файл | Что это |
|---|---|
| `src/tracker_core.py` | Мозг: правила сердечек, добрые сообщения, статистика, работа с JSON |
| `src/main.py` | Приложение для телефона: кнопки и экраны на [Flet](https://flet.dev) |
| `src/assets/icon.png` | Иконка приложения |
| `tracker.py` | Консольная версия |
| `pyproject.toml` | Название приложения и настройки сборки |
| `.github/workflows/build-apk.yml` | Автоматическая сборка APK на GitHub |

Добрые фразы лежат в начале `src/tracker_core.py` в словаре `MESSAGES`. Их можно менять как угодно, и они поменяются в обеих версиях.

## Установка на Android

APK собирается автоматически на GitHub, ничего ставить на компьютер не нужно.

1. Открой вкладку **Actions** в репозитории, выбери **«Собрать APK»**. Сборка запускается сама после каждого изменения в репозитории. Если её нет, нажми **Run workflow**.
2. Подожди, пока сборка станет зелёной ✅ (обычно 10–15 минут).
3. Открой её и внизу, в разделе **Artifacts**, скачай `kind-tracker-apk`. Внутри архива лежит файл `.apk`.
4. Перекинь APK на телефон и открой его. Android спросит, можно ли устанавливать приложения из этого источника: разреши.

На Xiaomi/HyperOS при установке может появиться предупреждение о «непроверенном приложении». Это потому, что оно не из магазина. Нажми «Всё равно установить».

## Где хранятся данные

Только в телефоне, в личной папке приложения. Никаких серверов и аккаунтов.

Если удалить приложение, данные удалятся вместе с ним. Поэтому иногда заходи в «Статистику» → «Мои данные» → «Сохранить копию». Из этого же файла всё восстанавливается кнопкой «Загрузить из файла». Туда же можно загрузить `tracker_data.json` от консольной версии, и наоборот.

## Консольная версия

Нужен только Python 3, без дополнительных библиотек:

```
python tracker.py
```

Данные хранятся в `tracker_data.json` в папке, из которой запущен скрипт.

## Запуск приложения на компьютере

Чтобы посмотреть приложение без телефона:

```
pip install "flet[all]==1.0.3"
flet run src/main.py
```
