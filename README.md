# 🌸 Добрый трекер

Трекер задач, который не ругает, а хвалит.

Я написала его, когда поняла, что Asana и Habitica доводят до невроза моего внутреннего достигатора. Дедлайны, красные просрочки, отнятое здоровье за невыполненные дела — всё это работает как топливо для тревоги. Здесь всё наоборот: нет дат, штрафов и напоминаний, а есть сердечки за любой шаг вперёд.

**Открыть трекер:** https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/

## Как это устроено

- **Короткие задачи** — сделала и получила 💛 золотое сердечко.
- **Длинные задачи** можно отмечать 💚 зелёным сердечком, даже если ты просто немного над ними поработала. Задача остаётся в списке, а прогресс копится. Когда закончишь совсем — 💛 золотое сердечко.
- **Задача дня** — трекер случайно выбирает одну задачу, если не знаешь, с чего начать. Не понравилась — можно выбрать другую.
- **Статистика** за 7 и 30 дней показывает только то, что получилось. Сколько осталось недоделанным, она не считает, и это специально.
- **Таблица по дням** для длинных задач: видно, как сердечки складываются в прогресс.

## Установка на телефон

Трекер работает в браузере, но его можно установить как обычное приложение. После установки интернет не нужен.

**Android (Chrome):**
1. Открой ссылку на трекер в Chrome.
2. Нажми меню ⋮ → «Установить приложение» или «Добавить на главный экран».
3. На Xiaomi/HyperOS иконка может не появиться, пока не разрешишь Chrome создавать ярлыки: Настройки → Приложения → Chrome → Другие разрешения → «Ярлыки на рабочем столе».

**iPhone (Safari):** открой ссылку в Safari → «Поделиться» → «На экран „Домой"».

## Где хранятся данные

Только в твоём телефоне, в памяти браузера. Никаких серверов и аккаунтов: никто, включая автора, твои задачи не видит.

Из этого следует одно: если очистить данные браузера или удалить приложение, задачи пропадут. Поэтому иногда заходи во вкладку «Статистика» → «Мои данные» → «Сохранить копию». Из этого же файла всё можно восстановить кнопкой «Загрузить из файла».

## Консольная версия

С неё всё началось: `main.py` — та же логика в терминале. Нужен только Python 3, без дополнительных библиотек.

```
python main.py
```

Данные хранятся в файле `tracker_data.json` рядом со скриптом. Формат у консольной и мобильной версии одинаковый, так что файл можно переносить туда и обратно.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Само приложение |
| `manifest.webmanifest` | Название и иконка для установки на телефон |
| `sw.js` | Сохраняет приложение в телефоне для работы без интернета |
| `icon-*.png` | Иконки |
| `tracker.py` | Консольная версия |

## Свой трекер

Хочешь переделать под себя? Все добрые фразы лежат в начале `index.html` (и `tracker.py`) в блоке `MESSAGES` — их можно менять как угодно, остальной код трогать не обязательно.
